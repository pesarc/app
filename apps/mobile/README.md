# @pesarc/mobile

Expo (React Native) app. Expo Router mirrors the web App Router, so screens map
1:1 to `apps/web`. Shares business logic via `@pesarc/sdk`, on-chain
interfaces via `@pesarc/abi`, and brand tokens via `@pesarc/ui`. This is
the whole reason for the monorepo — web and mobile are two skins on one core.
